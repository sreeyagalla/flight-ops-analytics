Flight Ops Analytics

A self-serve analytics engineering demo on real public flight data: a reproducible pipeline with automated data-quality checks, a governed metric layer, anomaly detection, and a Q&A agent that can only answer from computed data.

Honest scope

  • Real: all data is real and public (nycflights13: DOT flight records and NOAA weather, 2013, three NYC-area airports). Nothing is synthetic.
  • Solo demo: no real users or stakeholders, so there are no adoption or business-impact numbers.
  • Agent: numbers in answers are rendered from SQL results, and a test compares them with independently computed pandas values. The default question parser is rule-based and can misread unusual phrasing. The optional LLM translator has only been tested against a fake client, not a live API.
  • Not built: access management, cloud deployment, ML models or fairness analysis.
